# 首页核心入口跳转设计

## 目标

为首页“AI题库”和“AI智批”核心入口增加整卡跳转，让用户从首页直接进入对应业务页面。

## 跳转映射

- “AI题库”当前页跳转至 `https://liweimian.github.io/AIQuestion0820/`。
- “AI智批”当前页跳转至项目内 `fx-ai/homework-exam-unified-demo.html`。

## 交互设计

- 将两张卡片从静态 `article` 改为语义化链接，整张卡片均为点击区域。
- 不设置 `target="_blank"`，使用浏览器原生当前页跳转行为。
- 保留现有卡片文案、状态提示、视觉图形、布局和 hover 动效。
- 链接继承现有文字颜色并移除默认下划线，避免语义元素变化影响视觉。
- 键盘用户可聚焦卡片，并沿用现有 `focus-within` 视觉反馈。
- 其余“AI错因诊断”和“AI个性化练习”卡片保持静态，不增加跳转。

## 异常边界

- 外部“AI题库”页面已通过 HTTP 200 响应检查。
- 本地“AI智批”目标文件已确认存在于 `fx-ai/homework-exam-unified-demo.html`。
- 本次不增加 JavaScript 跳转、加载态或目标页面异常提示，链接行为交由浏览器处理。

## 验收标准

1. 点击“AI题库”卡片后，当前页进入指定外部地址。
2. 点击“AI智批”卡片后，当前页进入项目内统一作业考试页面。
3. 两个链接均不包含 `target="_blank"`。
4. 两张卡片可通过键盘聚焦和激活。
5. 两张卡片的文案、状态、视觉和尺寸保持不变。
6. 其他两张核心入口仍为非链接卡片。

## 验证

- 使用 Node 回归测试检查两张卡片的标签、目标地址、当前页行为及保留文案。
- 静态检查本地目标文件存在。
- 渲染首页确认链接默认样式未改变卡片视觉，并手动验证两个跳转目标。
