# “班级与学生”导航入口设计

## 目标

将首页右上角现有“错题本”入口调整为“班级与学生”，使入口语义明确指向班级与学生的阶段学情，而非个人错题管理。

## 设计

- 保留入口在顶部导航中的位置、尺寸、悬浮反馈与静态展示方式，不调整其他导航项或首页布局。
- 将入口的可见悬浮提示、无障碍名称统一从“错题本”改为“班级与学生”。
- 将原有“错题书本”图标替换为“阶段学情报告 + 趋势折线”图标，重点表达阶段学情及其变化，不以人物轮廓作为视觉主体。
- 本次只调整入口表达，不新增页面跳转、弹窗或数据交互。

## 验收标准

1. 页面中不再出现顶部入口名称“错题本”。
2. 悬停新入口时显示“班级与学生”。
3. 辅助技术读取到的入口名称为“班级与学生”。
4. 入口图标呈现阶段学情报告与趋势变化意象，不包含人物主体或错题叉号。
5. 其余顶部导航与首页卡片保持不变。

## 验证

- 静态检查 HTML，确认旧名称和旧图标路径已移除。
- 启动页面并进行视觉检查，确认图标、悬浮提示及布局符合设计。
