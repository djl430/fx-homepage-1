# 右上角入口精简设计

## 目标

从首页右上角工具栏移除“班级与学生”和“消息”两个入口，仅保留“班级/年级管理”和“我的资源”，让顶部工具区更聚焦。

## 页面调整

- 删除带有 `aria-label="班级与学生"` 的阶段学情入口及其图标。
- 删除带有 `aria-label="消息"` 的消息入口。
- 工具栏继续使用现有 Flex 布局，删除入口后由布局自然收拢，不增加占位元素。
- 保持“班级/年级管理”和“我的资源”的结构、样式及顺序不变。

## 消息功能清理

消息入口移除后，消息抽屉将无法再被用户访问，因此同步删除：

- 消息抽屉 HTML；
- 消息抽屉及消息列表专用 CSS；
- 消息抽屉的打开、关闭、遮罩点击和 Escape 键事件代码。

通用提示 Toast 与其他导航交互保持不变。

## 测试与验收

更新 `tests/homepage-navigation.test.mjs`，验证：

- 页面不包含“班级与学生”的无障碍标签、提示文本及阶段学情图标；
- 页面不包含“消息”入口、消息抽屉打开标记或消息中心 DOM；
- “班级/年级管理”和“我的资源”仍然存在；
- AI题库与 AI智批的现有链接行为不受影响；
- HTML 中不残留消息抽屉脚本查询或事件绑定。

## 非目标

- 不修改侧边栏导航；
- 不修改四个核心业务卡片；
- 不调整工具栏整体视觉样式；
- 不新增替代入口。
