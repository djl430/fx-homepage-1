# AI题库数量标签删除设计

## 目标

删除首页 AI题库卡片中的“近 7 日新增 12 份题单”数量标签，使卡片只展示标题、说明和视觉图形。

## 页面调整

- 从 AI题库卡片中删除完整的 `core-entry-signal` 元素。
- 保持 AI题库整卡链接、标题“AI题库”、说明“本地最新精品资源”和文件夹视觉图形不变。
- 保持 AI智批卡片中的“2 份新上传作业待确认”提示不变。
- 不删除共享的 `core-entry-signal` 样式，因为 AI智批仍在使用该组件。

## 测试与验收

更新 `tests/homepage-navigation.test.mjs`，验证：

- AI题库卡片不包含“近 7 日新增”“12”或“份题单”；
- AI题库卡片仍正确跳转到现有题库地址；
- AI智批卡片仍显示待确认作业数量；
- 其他首页卡片不受影响。

## 非目标

- 不调整 AI题库卡片的高度、颜色或底部视觉图形；
- 不修改 AI题库链接；
- 不修改 AI智批数量提示。
